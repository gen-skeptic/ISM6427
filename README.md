# Weather

A simple static weather app using the [Open-Meteo API](https://open-meteo.com/) (no API key needed).
Defaults to Boynton Beach, Florida; search any city from the top bar.

Glassmorphic UI, Catppuccin Mocha colors, JetBrainsMono Nerd Font.

## Deploy
Static site — no build step. On Netlify, point it at this repo; `netlify.toml` publishes the repo root.
Locally, just open `index.html`.
